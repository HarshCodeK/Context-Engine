# Extraction benchmark corpus

Run from the Context Studio project root:

```powershell
.\.venv\Scripts\python.exe benchmarks\run_extraction_benchmark.py
```

The benchmark generates a small deterministic corpus in memory: TXT, Markdown, CSV, JSON, HTML, PDF, DOCX, PPTX and XLSX. It checks labelled expected phrases, forbidden HTML script content, parser-native evidence locator types, evidence schema version, source SHA-256, stable block IDs across repeated runs, and the integrity of each Markdown range against its block-content hash.

All fixtures use `native_only`; no OCR engine, hosted model, network request or additional package is used. PDF and Office files are generated by the same parser libraries already required by the application. The benchmark emits a JSON report to stdout and exits non-zero if any fixture or check fails.

## What this measures

- Deterministic text preservation for known synthetic inputs.
- Presence of the expected source locator families.
- Stable source/block identities for identical bytes and parser locators.
- Correct Markdown offsets and content hashes.
- Expected removal of script content from HTML.

## What this does not measure

- Accuracy on real customer files, noisy scans, screenshots or handwriting.
- Visual reading order, complex table reconstruction, chart interpretation or semantic correctness.
- OCR quality (Tesseract is optional and was not installed in the validation environment).
- Runtime performance under production concurrency or very large documents.

This is a reproducible regression benchmark, not a marketing accuracy score. Before commercial claims, add a separately reviewed, consented and labelled corpus of representative real documents and measure field-level precision/recall and human-rated reading order. Do not place private customer documents in this synthetic fixture directory.
