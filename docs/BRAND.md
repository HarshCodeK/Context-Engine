# Brand and visual system

## Positioning

Context Studio is a document context workbench for people who need to prepare information for AI tools while keeping the source and extraction decisions visible.

Chosen tagline: **Make information work harder.** (29 characters)

Other directions considered:

- Keep the source in context. (27 characters)
- Know what enters your context. (30 characters)
- Documents, made AI-ready. (25 characters)

## Voice

Calm, precise, practical. Use sentence case and name actions clearly. Avoid hype words, fake savings, and claims that extraction is a semantic summary.

## Typography

- Geist Variable for interface text and headings.
- Geist Mono for file metadata, evidence identifiers, measured values, and technical labels.
- Body text starts at 13–16 px; helper text is at least 11 px. The main headline is large and editorial, while source and output panels remain readable at normal zoom.

## Icon direction

Use one outlined document shape with a small signal point. Keep the icon legible in grayscale and at favicon size. Do not place the app name or tagline inside the icon.

## Layout direction

An editorial workspace with a single upload action, a source queue, and a context preview. The three-cost thesis appears as a small supporting panel. No left sidebar, generic dashboard cards, gradient hero, glass surfaces, or decorative metrics. Motion is limited to state changes and hover feedback; reduced-motion preferences are respected.
